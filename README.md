# Tenglo

Tenglo is an online marketplace platform designed to connect customers with stores, products, ordering, payments, and delivery services.

## Project Vision

Tenglo is being developed as a real-world marketplace application rather than a simple demonstration project.

The long-term platform will support:

- Customer accounts
- Store accounts
- Product catalogues
- Categories
- Search
- Shopping cart
- Checkout
- Orders
- Payments
- Delivery and pickup
- Driver accounts
- Order tracking
- Order history
- Store management
- Administration
- Notifications
- Reports and analytics

## Development Approach

Tenglo is being built progressively:

1. Build the interface
2. Test it in the browser
3. Make features functional
4. Connect the frontend to the backend
5. Add database functionality
6. Add authentication and user roles
7. Add marketplace functionality
8. Test and improve
9. Deploy
